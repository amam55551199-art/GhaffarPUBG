Ghaffar PUBG DNS

An Android project for testing internet connection response times and managing Private DNS settings.

Features

- Test HTTPS response times across 10 requests.
- Show average, minimum, and maximum response times.
- Estimate response-time variation and count failed requests.
- Open Android Private DNS settings.
- Provide hotspot setup guidance for two Sharp phones.
- Launch PUBG Mobile Global if installed.

Important Notes

- HTTPS response time is not the same as PUBG server ping.
- DNS does not guarantee lower game latency.
- This project is source code, not a ready-to-install APK.

Status
